# MKR1: побудова RDF та робота з Wikidata

Робота Кравчука Іллі, номер у списку — **15**.

Для першого завдання використано генератор із параметром `--seed 15`.
Він сформував 22 записи, серед яких є повторення. Після очищення
ідентифікаторів у графі залишилося 20 різних рейсів і 314 тріплів.
Параметри класифікації: бюджетний рейс коштує не більше 89 євро,
а довгий триває щонайменше 150 хвилин.

У другому завданні залишок `15 % 6` дорівнює 3. Тому пошук виконується
для стадіонів Італії: клас `Q483110`, країна `Q38`, місткість `P1083`.
Початкова межа місткості — 20 000 місць; у Q1 відбираються значення
строго більші за цю межу.

Щоб відтворити результати, відкрийте термінал у цій папці та виконайте:

```powershell
python -m pip install -r requirements.txt
python gen_data.py --seed 15
python build_graph.py flights.csv params.json graph.ttl
python run_queries.py
```

Файл `graph.ttl` містить зв’язки рейсів з авіакомпаніями, містами та
країнами, а також домени й діапазони властивостей. Дати приведено до
єдиного формату; відсутня ціна не створює значення у графі. Відомості
про затримки оформлено окремими вузлами `rdf:Statement`. Для визначення
країн із частими вильотами кожен рейс враховується лише один раз.
Класи BudgetFlight і LongFlight можуть одночасно належати одному рейсу.

Кожен запит збережено окремо у файлі `.rq`. Q1 показує найбільші стадіони
та, за наявності, їхні сайти. Q2 групує стадіони за безпосереднім регіоном
`P131` і рахує різні об’єкти. Q3 сортує результати за населенням регіону.
Пошук класу охоплює також його підкласи.

Таблиці відповідей записані в `q1.csv`, `q2.csv` і `q3.csv`. Перші результати
наведено в `ANSWERS.md`, а момент отримання з Wikidata — у `meta.json` (UTC).
Якщо перший запит знайде менше п’яти рядків, межа місткості зменшиться
вдвічі; оновлений запит і примітка до відповідей збережуть нове значення.
